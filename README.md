# Svaha

Учебный Go-проект со страницами входа и регистрации. Для сборки нужен Go 1.25.5 или новее. Проект использует стандартную библиотеку Go.

## Запуск

Выполняйте команды из корня репозитория.

```sh
go run ./cmd/svaha
```

- [Главная страница](http://127.0.0.1:8080/) открывает форму входа.
- [Страница регистрации](http://127.0.0.1:8080/register) открывает форму создания аккаунта.
- Параметр `-addr` меняет адрес прослушивания. Например, `go run ./cmd/svaha -addr 127.0.0.1:8081`.

Обе формы пока показывают сообщение о недоступности при отправке. Хранилище пользователей, проверка паролей и сессии ещё не реализованы.

## Структура

| Путь | Назначение |
| --- | --- |
| `cmd/svaha/main.go` | Точка входа и запуск веб-сервера |
| `internal/web/handler.go` | HTTP-маршруты и рендеринг шаблонов |
| `internal/web/templates/login.html` | Главная страница с формой входа |
| `internal/web/templates/register.html` | Страница регистрации |

HTML-шаблоны встраиваются в бинарник при сборке.
