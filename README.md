# Svaha

Svaha — веб-приложение знакомств на Go. В нём можно заполнить анкету, искать людей по городу и предпочтениям, ставить лайки и переписываться после взаимного лайка. Аккаунты, фотографии, сообщения и вложения хранятся в PostgreSQL.

## Быстрый запуск

Нужны Go 1.25.5 или новее и PostgreSQL 18. В GoLand запустите пакет `cmd/svaha`. Из терминала используйте команду из корня проекта.

```sh
go run ./cmd/svaha
```

Откройте [http://127.0.0.1:8080](http://127.0.0.1:8080). Другой адрес можно задать через `-addr`, например `go run ./cmd/svaha -addr 127.0.0.1:8081`.

### Подключение базы

- Если локальный кластер уже подготовлен в `~/.local/share/svaha/postgres`, Svaha использует базу `svaha` через Unix-сокет `/tmp` на порту `55432` от имени пользователя Linux. Приложение запускает этот PostgreSQL при необходимости и останавливает его при штатном завершении, если запустило само.
- Для другой установки запустите PostgreSQL, создайте базу и передайте приложению `SVAHA_DATABASE_URL`. Пользователю базы нужны права на создание таблиц, представлений и индексов для миграций.

Пример для PostgreSQL с локальным сокетом `/var/run/postgresql` и настроенным входом для текущего пользователя Linux:

```sh
createdb -h /var/run/postgresql svaha
SVAHA_DATABASE_URL='host=/var/run/postgresql dbname=svaha sslmode=disable' go run ./cmd/svaha
```

В GoLand `SVAHA_DATABASE_URL` можно задать в переменных окружения конфигурации запуска. Если используете `.env`, загрузите его в той же конфигурации. Файл исключён из Git. Тестовые анкеты и учётные данные локальной базы не входят в репозиторий. На новой установке создайте аккаунты через форму регистрации.

Миграции встроены в приложение. При запуске Svaha сверяет журнал `schema_migrations` с SQL-файлами, проверяет их контрольные суммы SHA-256 и применяет новые версии в одной транзакции. Если файл уже применённой миграции изменился или пропал, запуск остановится с ошибкой. Изменения схемы добавляйте новым нумерованным SQL-файлом в `internal/postgres/migrations/`. При первом запуске с новым форматом Svaha заполняет контрольные суммы для старых записей по файлам текущей сборки.

## Как пользоваться

| Страница | Назначение |
| --- | --- |
| `/` | Вход по логину и паролю |
| `/register` | Создание аккаунта |
| `/profile`, `/profile/edit` | Просмотр и редактирование анкеты и галереи |
| `/search` | Поиск по предпочтениям и городу |
| `/likes` | Входящие лайки от людей, с которыми ещё нет чата |
| `/chats` | Переписка после взаимного лайка |
| `/profile/blocks` | Просмотр и снятие блокировок |

- **Анкета.** Регистрация и редактирование анкеты доступны с 18 лет. Укажите город, предпочтения, описание и увлечения. Можно добавить до 10 фотографий JPEG или PNG, до 4 МБ и 2048 × 2048 пикселей на файл. В чужой анкете видны имя, город, описание, увлечения и фото. Email, телефон и точная дата рождения остаются в личной карточке.
- **Поиск.** Нажатие на карточку открывает анкету. Свайп вправо ставит лайк, влево пропускает. Те же действия доступны кнопками. Когда заканчиваются подходящие анкеты без чата, поиск повторяет их.
- **Совпадение.** Ответный лайк можно поставить прямо в разделе «Кто меня лайкнул». При взаимном лайке появляется чат у обоих участников, а анкеты скрываются из поиска и входящих лайков. Чаты отсортированы по последней активности. В списке видно число непрочитанных сообщений. Из переписки можно открыть профиль собеседника. Удаление чата стирает переписку у обоих и сбрасывает оба лайка.
- **Сообщения.** Можно редактировать текст и подписи своих сообщений или удалять свои сообщения у обоих участников. К сообщению можно прикрепить один файл. Фото JPEG и PNG до 4 МБ, аудио MP3, WAV, OGG, M4A и WebM и видео MP4 и WebM до 20 МБ. Голос можно записать с микрофона в поддерживаемом браузере на локальном адресе или по HTTPS. Лимит записи — две минуты.

## Безопасность и модерация

- Чужую анкету можно заблокировать или отправить на неё жалобу. Блокировка скрывает обе анкеты друг от друга в поиске, входящих лайках, чатах и по прямым ссылкам. После разблокировки взаимный лайк и история восстанавливаются.
- Жалобы сохраняются в таблице `profile_reports`. Их может проверять администратор с доступом к PostgreSQL. Повторная жалоба на ту же анкету обновляет причину и комментарий.
- Вход ограничен восемью попытками на логин и тридцатью на IP за пять минут. Счётчики действуют в пределах экземпляра приложения. Для IP используется адрес соединения.
- Повторная отправка одного и того же запроса из формы чата сохраняет только одно сообщение. Вложения передаются из PostgreSQL частями с повторной проверкой доступа при чтении.

## Структура

```text
cmd/svaha/                    запуск HTTP-сервера и локального PostgreSQL
internal/
  postgres/                   запросы, проверка доступа и журнал миграций
    migrations/               версионированные изменения схемы
  web/                        HTTP-маршруты, сессии, формы и медиа
    safety.go                 жалобы и блокировки
    templates/
      auth/                   вход и регистрация
      profile/                личная анкета и редактор
      discovery/              поиск, входящие лайки и чужие анкеты
      chats/                  список чатов, переписка и её обновление
      shared/                 навигация и общие стили
```

## Проверка

```sh
go build ./...
go test -race ./...
go vet ./...
```

GitHub Actions запускает сборку, `go vet` и тесты с PostgreSQL 18. Для локального запуска интеграционных тестов задайте `SVAHA_TEST_DATABASE_URL` со строкой подключения к отдельной тестовой базе. Роли в этой базе нужны права на создание схемы. Тесты создают свою временную схему и удаляют её после завершения. Без этой переменной выполняются остальные тесты Go. Интеграционный сценарий проверяет запуск на временной схеме, обновление журнала миграций, поиск, взаимные лайки, блокировки, повторную отправку сообщения и доступ к вложениям. Для проверки переписки вручную создайте два аккаунта, поставьте взаимные лайки и откройте чат из каждого аккаунта в отдельных профилях браузера.
