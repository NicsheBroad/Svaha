# Repository Guidelines

## Структура проекта

`Svaha` — учебный Go-проект со страницами входа и регистрации. Модуль Go 1.25.5 находится в корне репозитория. Точка входа веб-приложения — `cmd/svaha/main.go`. В пакете `internal/web/` находятся HTTP-маршруты и встроенные HTML-шаблоны.

## Сборка и запуск

Выполняйте команды из корня модуля.

- `go run ./cmd/svaha` запускает веб-сервер на `127.0.0.1:8080`.
- `go build ./...` проверяет сборку всех пакетов.
- `go test ./...` запускает тесты во всех пакетах.
- `go vet ./...` проверяет типичные ошибки Go, например неверные аргументы функций форматирования.

## Стиль и тестирование

Форматируйте изменённые Go-файлы с помощью `gofmt`. Для отступов в Go используйте табуляцию. Для новых Go-идентификаторов следуйте стандартной нотации. Используйте `mixedCase` для внутренних имён, `MixedCaps` для экспортируемых. Сохраняйте существующие пути пакетов, в том числе `cmd/svaha/` и `internal/web/`.

Автоматических тестов и требований к покрытию пока нет. При добавлении тестов используйте стандартный пакет `testing`, файлы `*_test.go` рядом с исходниками и функции `Test...`. При правках HTML откройте страницу в браузере и проверьте отображение.

## Коммиты и pull requests

В истории встречаются короткие сообщения на русском и английском, например `add home_page and tg bot`. Указывайте, что изменилось, например «Добавить страницу регистрации». В pull request опишите изменение и выполненные проверки. Добавьте ссылку на задачу, если она есть, и скриншот при изменении страницы.

## Правила работы

Всегда отвечайте по-русски и объясняйте сложное простыми словами. Перед изменением кода объясняйте свои действия. Удаляйте файлы только с разрешения. Пишите чистый, понятный код и соблюдайте стиль проекта.
